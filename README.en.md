# Chinese-style School as well as Home (CSSAHUV)

[简体中文](./README.md) · English


Chinese-style School as well as Home was created by 江竹雨offical / Noel-Cornehl. Build a classroom with desks, chairs and teaching equipment, add a Seewo display or projector, and fit out the lab with interactive cabinets. The mod also provides household decorations and entities such as cats.

## What changed in the RongMC 26.3 port

Adapts Forge registration, menus and networking to Fabric. The port fixes a cyclic Seewo model, a missing projector texture, structure-template lookup and menu decoding when opening the laboratory cabinet.

## Installation

Download **v0.90.9-rongmc.2+26.3** from [GitHub Releases](https://github.com/OpenRongMC/CSSAHUV/releases/tag/v0.90.9-rongmc.2%2B26.3) for Minecraft Java **26.3** on **Fabric** with **Java 25**. Dependencies include [Fabric API](https://modrinth.com/mod/fabric-api). Place the release JAR in the instance’s `mods/` directory. Install the same release on the client and server. Try older Forge worlds on a copy and check interactive blocks, entities and structure templates separately.
